# 日照银行“十五五”战略规划执行管理平台

依据现有线上 DEMO 重建的可维护版本。页面名称改为日照银行，任务、指标、部门、目标和静态进度保留原 DEMO 内容；不是日照银行正式规划或真实经营数据。

## 启动

Node.js 22.13 及以上。

```sh
npm install
npm run dev
```

```sh

```

## 已重建范围

- 登录与演示账号识别，总行、牵头及协同部门视角。
- 战略驾驶舱：年度、板块筛选，统计卡片、部门明细、系统清单、任务分布。
- 战略任务：搜索及筛选、卡片和表格视图、详情、实施举措、完成标准。
- 全周期与单年度完成标准达成表，年度计划目标、最终目标差异。
- 年度推进：标准列表、状态及业务筛选、关联任务填报入口。
- 指标任务：筛选、年度目标、完成值、差值、完成率、趋势与对比图、年度明细。
- 部门演示填报：指标数值、非指标完成情况与进度、备注；总行可查看已填报内容。
- 智能助手入口：本地站内任务检索和使用说明；没有连接外部大模型。

## 原始数据及后续 Excel 更新

数据独立于组件，位于 `data/`：

| 文件 | 内容 | 数量 |
| --- | --- | --- |
| tasks.json | 任务、部门、举措、原始完成标准文本、年度及总体示例进度 | 95 |
| standards.json | 分解完成标准、目标类型、单位、最终目标、时间及年度目标 | 299 |
| indicators.json | 2025 基期值及 2026—2030 指标目标 | 43 |
| systems.json | 系统建设事项 | 31 |
| accounts.json | 原 DEMO 演示账号和部门映射 | 32 |

收到 Excel 后，先按实际表头建立映射，核对任务编号、板块、牵头/协同部门、实施时间、举措、完成标准、目标单位、基期和年度目标。替换以上数据并保持 `taskId`、`linkedIndicatorIds` 关联完整。此版没有预设未知 Excel 格式或实现未验证的自动导入。

任务内容由原站公开前端脚本中的静态字面量提取，提取过程不执行原站脚本。`scripts/extract-reference.mjs` 是溯源工具，读取项目上一级 `reference/demo-bundle.js`；应用运行和构建只依赖本项目内的数据文件，无需该参考文件。测试在参考数据存在时逐项比对原数组。

## 保留口径及当前边界

- 原始截止日期 `2026-07-20`。任务 95、牵头部门 24、逾期任务 6、2026 年年度项 132。
- 驾驶舱 89% 为任务年度进度均值；年度推进 88% 为完成标准行对应进度均值。两者统计粒度不同，此版保留原口径。
- 总体和年度进度沿用静态演示值；新填报不会改写这些示例进度。指标详情中的完成率基于本机新填报值计算。
- 原数据中不完整的标准拆分、原单位、旧银行地域及业务内容保持不变，待提供 Excel 或源码后核对。
- 演示登录和部门可见性为前端演示逻辑，并非生产认证。填报保存在当前浏览器 `localStorage`，不跨设备或用户共享。服务器没有实际经营数据数据库。
- 品牌区暂用日照银行文字标识，后续可替换正式 Logo 素材。
- 页面式查询工具 `search_strategy_tasks` 按当前演示账号可见范围检索。浏览器支持 WebMCP 时注册；不支持时不影响页面使用。
